# day11-login-system
# 🔐 Login & Registration System (Flask)

A clean and responsive **Login + Registration system** built using  
**HTML, CSS, JavaScript, and Flask (Python)** as part of my **30 Days Coding Challenge – Day 11**.

---

## 🚀 Features

- User Registration & Login
- Username length validation
- Email must end with `@gmail.com`
- Phone number (digits only, 10 digits)
- Strong password validation  
  (must contain letter, number & symbol)
- Error messages for invalid input
- Responsive UI (Desktop & Mobile)
- Data stored locally using `users.json`

---

## 🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Storage: JSON file
